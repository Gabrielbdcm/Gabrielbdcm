### Simulador de BD com JS
Este projeto é um sistema simples de cadastro de alunos
desenvolvido com HTML e JavaScript, cuja finalidade é aprender
a usar arrays na prática. O programa armazena nomes, cursos
eidades em três arrays paralelos e permite adicionar, pesquisar,
listar e excluir alunos, demonstrando operações essenciais como
push, splice e laços de repetição para manipulação de dados.
